# Инструкция по начальной настройке программы

## Подготовка интеграции с телеграмом

### Создание бота

1. Напишете в Телеграм [https://t.me/BotFather](BotFather) команду "/start"
2. Напишите команду "/newbot"
3. Выберите имя вашего бота, которое будут видеть пользователи
4. Выберите идентификатор вашего бота (он должен заканчиваться на "bot")
5. Скопируйте токен, который пришлет BotFather и сохраните его в константу "ВКМ токен управления ТГБотом"

### Создание группы

1. Создайте группу в Телеграм
2. Добавьте в группу только что созданного бота
3. Назначьте боту права администратора

### Получите идентификатор группы

1. Напишите любое сообщение в группу
2. С помощью браузера или Postman выполните запрос `https://api.telegram.org/bot[ВашТокен]/getUpdates`. В полученном JSON найдите идентификатор группы, в которой получено сообщение, и сохраните его в константу "ВКМ идентификатор группы для оповещения".

## Заполнение необходимых данных

### Заполнение справочников

1. Добавьте сотрудников в справочник "ВКМ сотрудники".
2. Добавьте необходимые графики работ в справочник "ВКМ графики работ".

### Заполнение регистров
1. Откройте обработку "ВКМ заполнение графика работы"
2. Выберите период, график работы, в поле выходные дни цифрами через запятую обозначьте выходные дни (1 - понедельник, 2 - вторник и тд.)
3. Нажмите кнопку заполнить.
4. Откройте регистр "ВКМ условия оплаты сотрудников" и для каждого сотрудника заполните оклад и процент от выручки.

### Заполнение констант

1. Напишете в Телеграм [https://t.me/BotFather](BotFather) команду "/start"
2. Напишите команду "/newbot"
3. Выберите имя вашего бота, которое будут видеть пользователи
4. Выберите идентификатор вашего бота (он должен заканчиваться на "bot")
5. Скопируйте токен, который пришлет BotFather и сохраните его в константу "ВКМ токен управления ТГБотом"

6. Создайте группу в Телеграм
7. Добавьте в группу только что созданного бота
8. Назначьте боту права администратора

9. Напишите любое сообщение в группу
10. С помощью браузера или Postman выполните запрос `https://api.telegram.org/bot[ВашТокен]/getUpdates`. В полученном JSON найдите идентификатор группы, в которой получено сообщение, и сохраните его в константу "ВКМ идентификатор группы для оповещения".
11. Заполните константы "ВКМ номенклатура абонентская плата"
12. Заполните константу "ВКМ номенклатура работы специалиста"
